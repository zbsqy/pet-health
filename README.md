# 毛孩子咨询 · 宠物健康与环境数字助手

单文件网页应用，参赛作品。

## 内容

- 猫狗分诊、宠物购买、猫粮狗粮向导、咨询流程
- 健康自测：5 个问题生成宠物健康档案卡，可导出 1080×1350 图片
- 环境自查：从症状出发（乱尿 / 夜间嚎叫 / 躲藏 / 抓挠 / 食欲下降 / 拆家 / 吠叫），进入 3D 房间逐项判断哪件家具摆错了，改完给出改造前后对比
- 房间搭配：4 × 3.2 m 真实尺度，11 件宠物家具可拖拽摆放，自动给动线冲突提示
- 宠物视角：相机降到猫 28 cm / 狗 52 cm 的眼高，86° 广角贴地看同一个房间，建议文案随视角整套替换

## 技术

- 3D 渲染：Aholo Viewer SDK v1.11.0（createViewer / PerspectiveCamera / ShadowMap / TAA）
- 家具模型：Aholo Lux3D text-to-3D（G1，faceCount 30000）生成 7 件 GLB，比例按包围盒实测校准
- 环境归因：7 条症状规则、共 25 个空间检查项，拖动物件时实时重算
- 交付：单个 index.html，图片 base64 内嵌，无构建步骤

## 说明

- 打开后首次点击「房间搭配」需要联网加载 3D 引擎与模型（约 4–15 MB，走 CDN）
- 健康自测的图片导出组件已内联，离线可用
- 页面文案表述为「居家观察参考」，不替代临床诊断
- 门店地址、电话、二维码以公众号 / 小程序为准，未在页面内编造
